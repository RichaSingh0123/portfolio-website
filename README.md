# Personal Portfolio Website
This is my personal portfolio website created to present my projects, education, and contact information in a clear and professional way. It serves as a central place to showcase my academic and early professional work.

# Features
- Responsive layout and clear UI  
- Sections for projects, education, skills, and contact details  
- Clickable project cards linking to live demos  
- Light and dark mode support
